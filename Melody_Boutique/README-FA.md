# راهنمای Melody Boutique

## اجرای سریع
1. فایل ZIP را Extract کنید.
2. وارد پوشه `Melody_Boutique` شوید.
3. روی `index.html` دوبار کلیک کنید تا سایت در مرورگر باز شود.

## ساختار پوشه
- `index.html` ظاهر و بخش‌های سایت
- `styles.css` استایل‌ها
- `app.js` منطق سایت (سبد، جست‌وجو، فیلتر، کد تخفیف)
- `products.js` لیست محصولات
- `store-config.js` تنظیمات فروشگاه (لینک‌ها، کد تخفیف، تخفیف سراسری)
- `images/` همه عکس‌ها (محصولات و بک‌گراندها)، راهنمای اسم فایل‌ها داخل `images/README.txt`
- `PRODUCT-EXAMPLE.js.txt` نمونه آماده‌ی کپی برای افزودن محصول

## افزودن محصول
1. عکس‌ها را با اسم‌هایی مثل `1.jpg` و `2.jpg` داخل پوشه `images` بریز.
2. متن نمونه را از `PRODUCT-EXAMPLE.js.txt` کپی کن و داخل `products.js` در آرایه `window.PRODUCTS` بچسبان (بعد از `}` محصول قبلی کاما بگذار).
3. فیلدهای مهم:
   - `images`: اسم فایل عکس‌ها، یک یا دو عکس (`["1.jpg", "2.jpg"]`)
   - `category`: یکی از `tops`، `dresses`، `outerwear`، `bottoms`، `bags`، `accessories`
   - `featured: true`: نمایش در بخش «محصولات ویژه»
   - `tags`: کلمه‌های کلیدی برای جست‌وجو
   - `sizes: []` برای کیف و اکسسوری
   - `id` باید یکتا باشد.

محصول در بخش «همه» و در دسته‌بندی خودش نمایش داده می‌شود و با جست‌وجوی نام، رنگ، دسته یا برچسب پیدا می‌شود.
اگر شناسه تکراری باشد یا دسته اشتباه نوشته شده باشد، در کنسول مرورگر هشدار نشان داده می‌شود.

## عکس‌های بک‌گراند سایت
اسم فایل‌ها را دقیقاً همین‌ها بگذار و داخل `images` بریز:
- `hero-1.jpg`، `hero-2.jpg` برای بخش اصلی صفحه
- `cat-tops.jpg`، `cat-dresses.jpg`، `cat-outerwear.jpg`، `cat-accessories.jpg` برای دسته‌ها
- `promo.jpg` برای بنر کمپین

اگر فایلی نباشد، کادر پیش‌فرض نمایش داده می‌شود.

## تغییر لینک تلگرام و اینستاگرام
فایل `store-config.js` را باز کنید:
- `telegramUsername`: آیدی تلگرام بدون @
- `telegramProfileUrl`: لینک پیوی
- `instagramUrl`: لینک پیج اینستاگرام

دکمه تلگرام در سبد خرید از لینک اشتراک‌گذاری رسمی تلگرام استفاده می‌کند تا متن سفارش آماده شود و کاربر چت مقصد را انتخاب کند. اگر بخواهید پیام مستقیم و خودکار به صاحب فروشگاه برسد، باید ربات تلگرام و بک‌اند امن راه‌اندازی شود؛ توکن ربات را هرگز داخل فایل‌های عمومی سایت قرار ندهید.

## کد تخفیف
در `store-config.js` در آرایه `coupons` کد جدید اضافه کنید:

```js
{ code: "FRIDAY30", type: "percent", value: 30, active: true,
  minSubtotal: 500000, startsAt: "2026-11-13T00:00:00",
  endsAt: "2026-11-13T23:59:00", appliesTo: "all", maxUses: 0 }
```

- `type: "percent"` یعنی درصدی؛ `type: "fixed"` یعنی مبلغ ثابت به تومان.
- `minSubtotal` حداقل جمع خرید برای فعال شدن کد است.
- `startsAt` و `endsAt` تاریخ/ساعت محلی مرورگر هستند. برای بدون محدودیت زمانی رشته خالی `""` بگذارید.
- `appliesTo: "all"` برای همه محصولات است. می‌توانید نام دسته‌بندی مثل `"bags"` یا آرایه‌ای از شناسه محصولات هم بدهید.
- `maxUses: 0` یعنی محدودیت تعداد استفاده ندارد.

## تخفیف خودکار همه محصولات
در `store-config.js` بخش `sale` را تغییر دهید. برای خاموش کردن، `enabled: false` کنید.

## نکات مهم نسخه فعلی
- سبد خرید، علاقه‌مندی‌ها و کد تخفیف در مرورگر همان دستگاه با `localStorage` نگهداری می‌شوند.
- این نسخه درگاه پرداخت، موجودی مشترک بین کاربران، پنل مدیریت امن یا ثبت سفارش مرکزی ندارد.
- تخفیف و قیمت در نسخه فرانت‌اند برای نمایش و تست هستند و به‌تنهایی مبنای پرداخت واقعی نیستند.
- نام فایل عکس‌ها حساس به حروف است (`1.jpg` با `1.JPG` فرق دارد)؛ بهتر است همه را با حروف کوچک بنویسید.

## انتشار با Cloudflare Pages و GitHub
اگر پروژه Cloudflare Pages متصل به GitHub است:
1. فایل‌های داخل این پوشه (شامل پوشه `images`) را در ریشه Repository قرار دهید؛ خود پوشه `Melody_Boutique` را تو در تو آپلود نکنید.
2. Commit/Push کنید یا از روش Upload فایل‌ها در GitHub استفاده کنید.
3. در Cloudflare Pages، پروژه متصل به همان Repository و شاخه `main` را انتخاب کنید.
4. برای سایت استاتیک بدون فریم‌ورک، Build command را خالی/`exit 0` و Build output directory را `/` یا ریشه پروژه تنظیم کنید.
5. پس از Deploy، لینک `pages.dev` را باز کنید. وجود `index.html` در ریشه خروجی ضروری است.

## آیکون سایت (Favicon و آیکون گوشی)
آیکون‌ها از لوگو Melody ساخته شده‌اند و همه داخل پوشه اصلی هستند:
- `favicon.ico`، `favicon-16x16.png`، `favicon-32x32.png`: آیکون تب مرورگر
- `apple-touch-icon.png` (۱۸۰×۱۸۰): آیکون صفحه اصلی آیفون/آیپد
- `android-chrome-192x192.png`، `android-chrome-512x512.png`، `android-chrome-maskable-512x512.png`: آیکون اندروید و نصب سایت به‌عنوان اپ
- `mstile-150x150.png` و `browserconfig.xml`: کاشی ویندوز
- `og-image.png` (۱۲۰۰×۶۳۰): تصویری که هنگام اشتراک لینک در تلگرام و اینستاگرام نمایش داده می‌شود
- `site.webmanifest`: تنظیمات نصب سایت (نام، رنگ و آیکون‌ها)

**نکته برای لینک‌های اشتراکی:** تلگرام و سایر شبکه‌ها برای `og-image` به آدرس کامل نیاز دارند. بعد از انتشار سایت، در `index.html` مقدار `og:image` را به آدرس کامل تغییر بده، مثلاً `https://نام-سایت.pages.dev/og-image.png`.

اگر لوگو تغییر کرد، آیکون‌ها را دوباره با همان فایل جدید بساز یا از ما بخواه.
